# DP-FTRL and Matrix Mechanisms

This sub-package contains all the code necessary to define, optimize,
instantiate, and use correlated noise ("DP-FTRL") mechanisms.

Notation, participation schemas, and parameterized matrix classes are
documented in the
[Matrix Factorization notation](../../docs/matrix_factorization.md)
guide. That page is also linked from the generated Public API docs for
`jax_privacy.matrix_factorization`.
